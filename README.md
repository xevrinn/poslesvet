# Послесвет

Веб-дневник атмосферы дня для трека ArtTech, Genesis Hackathon 2026. Он предназначен для людей, которые хотят сохранить вместе историю дня, фотографии и музыку. Формат результата — интерактивная страница воспоминания с фотолентой, музыкой и опциональной озвучкой.

## Запуск

Скачайте или клонируйте репозиторий. Из его корня запустите:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/ в актуальном Chrome, Firefox или Edge. Сборка, аккаунт, API-ключи и установка пакетов не требуются.

Нажмите «Записать день». Добавьте текст, от одной до восьми фотографий и песню. Для ссылки укажите темп и характер звучания. Для аудиофайла можно указать темп на случай, если анализатор не сможет уверенно определить его. После сохранения день сразу открывается и появляется в архиве. В поиске можно использовать слова из текста или названия. Для просмотра слайдов используйте стрелки или кнопку запуска смены кадров.

## Визуальная система

- Дата, заголовок, рамка, фотолента и подпись занимают одинаковые места во всех воспоминаниях. Основные референсы — фотографический альбом, плёночное зерно и геометрическая графика.
- Слова о спокойствии, спешке и радости задают теплоту палитры, плотность фактуры и угол её штрихов. Для других текстов предусмотрена нейтральная композиция. Название собирается из слов записи и сохраняется вместе с днём.
- Средние цвета всех фотографий смешиваются с оттенком, выбранным по тексту. Фотографии пользователя формируют кадры, а количество снимков определяет длину ленты.
- Музыкальный темп задаёт 6,2, 4,1 или 2,4 секунды на кадр. Для аудио анализируется повторяемость всплесков огибающей по первому каналу. Выбранный характер звучания меняет контраст, яркость и насыщенность. Озвучка зависит от скорости и высоты голоса, а наличие русского голоса зависит от браузера и устройства.
- Под каждым воспоминанием доступна краткая расшифровка оформления.

## Примеры в архиве

| Папка | Настроение | Приём |
| --- | --- | --- |
| Осенний парк и какао | Тихий день | Охристая рамка, мягкая обработка, долгие кадры |
| Ночь перед сдачей проекта | Напряжённый день | Синий акцент, плотная фактура, быстрый ритм |
| Солнце над тихим морем | Светлый день | Светлая палитра, лёгкая фактура, средний ритм |

Все три примера используют вымышленные записи, процедурные иллюстрации и синтезированные мелодии, созданные для этого прототипа. Карточки демонстрационных дней открываются без добавления личных данных.

## Хранение и инструменты

В IndexedDB каждый день представляет отдельную запись с уникальным ID, названием, текстом, фотографиями, песней и параметрами оформления. Это папка внутри дневника. Личные материалы остаются в браузере. Архив привязан к профилю и адресу сайта, поэтому очистка данных сайта удаляет записи и перенос между устройствами не предусмотрен. Для песен по ссылке проигрывание происходит на музыкальном сервисе.

В разработке использованы ChatGPT (код, документация и сценарии примеров), HTML, CSS и JavaScript, Canvas, IndexedDB, Web Audio и Web Speech. Иллюстрации подготовлены с Python/Pillow. У прототипа нет внешних runtime-зависимостей. Для своих записей используйте материалы, которыми вы вправе пользоваться.
